StationLedger

StationLedger is a Java application I created for my Year Up United capstone project.

I wanted to build something that connected to my previous experience running a gas station. The idea was to create a simple financial ledger that could keep track of daily transactions, organize records, and make it easier to look back at business expenses and deposits.

Features

Add deposits and payments.

Record current or past transactions.

Save and load transactions using a CSV file.

View transaction history and filter deposits or payments.

Generate monthly and yearly financial reports.

Search transactions using different filters.

Employee and Manager accounts with different permissions.

Manager password authorization for restricted features.

Technologies Used

Java

Maven

CSV file handling

BCrypt for password hashing

Java Swing for password input
